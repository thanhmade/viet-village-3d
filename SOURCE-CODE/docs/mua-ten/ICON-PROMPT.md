# Icon Mưa Tên

Generated with the built-in imagegen tool. New opaque PNG, 1254 × 1254, no text; copied unchanged into the repo. No image reference was supplied to the image-generation call; the prompt was written after inspecting the user's skill reference. The tool did not expose a selectable model/quality/size option; only prompt and transparent_background=false were specified. This is concept art for UI, not a runtime screenshot.

Final prompt:

Use case: stylized-concept. Asset: a finished square skill icon for a Vietnamese wuxia fantasy RPG, Mưa Tên (Rain of Arrows). Cinematic premium painted game UI illustration, no text. Main readable silhouette: a shower of FIVE distinct long golden energy arrows diving steeply DOWNWARD from upper half into a luminous elliptical golden battle formation circle in the lower half. Largest central arrow tip points DOWN, two supporting arrows on either side. Electric azure blue qi coils around the descending golden shafts. Compact gold-white contact sparks inside the ring, a hint of a blue celestial vortex above. Deep midnight navy background, amber gold highlights, restrained vivid blue. Strong grouped shapes and bold contrast that remain recognizable at 48px, rich metallic light but uncluttered, all arrow tips clearly distinguishable from upward launch arrows. Center all essential imagery within a circular safe area occupying 80 percent of the square; keep corners dark. Elegant circular subtle antique gold rim, no lettering, no number, no UI label, no watermark, no characters, no landscape. Must differ clearly from a single horizontal piercing arrow and a three-arrow fan icon. This is one standalone icon, not a sheet.
